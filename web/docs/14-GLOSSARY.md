# Glossary

## Terms

| Term | Definition |
|------|------------|
| SC | Service Charge — percentage added to base fare |
| VAT | Value Added Tax — 15% of SC in Ethiopia |
| Station Fee | Percentage of SC paid to the station |
| Commission | Percentage of SC earned by ticketer |
| Tariff | Base fare for a route |
| ETB | Ethiopian Birr (currency) |
| Cents | 1/100 of ETB, used for integer money |
| Ticketer | Person who issues tickets at station |
| Agent | Vehicle owner/operator who registers vehicles |
| Station Controller | Manager who oversees station operations |
| Waldaa Konkolaachistootaa | Drivers' association (Afaan Oromo) |
| Buufata | Station/terminal (Afaan Oromo) |
| Offline-first | App works without internet, syncs when online |
| Idempotency | Same request can be sent multiple times safely |
| JWT | JSON Web Token — signed token for authentication |
| Refresh token | Long-lived token to get new access tokens |
| Access token | Short-lived token for API requests |
| Mutation | A change to data (create, update, delete) |
| Sync | Sending local changes to server / receiving server changes |
| Conflict | When local and server versions disagree |
| Version vector | Number tracking how many times a row has been updated |
